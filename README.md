# Журнал событий устройства

## Назначение системы
Система позволяет отслеживать включения, выключения, показания датчиков и фиксировать ошибки для последующей диагностику

## Структура базы данных
База данных состоит из двух таблиц:
Таблица	Столбцы
devices	device_id (PK), name, location
events	event_id (PK), device_id (FK → devices), event_time, event_type, value

Типы событий (`event_type`): 'включение', 'выключение', 'показание', 'ошибка'

## Порядок разворачивания базы данных с нуля
1. `git clone git@github.com:Namiellee/Gubatova.git`
2. >>`cd Gubatova`
3. `sqlite3 shop_devices.db < schema.sql`
4. Заполните данными: `sqlite3 shop_devices.db < data.sql`
5. выполните запросы: `sqlite3 -header -column shop_devices.db < queries.sql`
